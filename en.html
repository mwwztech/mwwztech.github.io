FAQ

Questions before we start

Can MWWZTech replace HALCON directly?

It is not a drop-in API replacement. It provides comparable algorithm capabilities; existing projects need an interface, operator and scenario migration assessment.

Which platforms and languages are supported?

C, C++, C#, Python; Windows, Linux, Ubuntu, Android; x86, x86_64, aarch64. Module availability may vary by platform — please confirm for your target setup.

How does licensing and pricing work?

Per project / per module. Share your application, image size and cycle-time requirements, and we will propose the right scope and quote.

Do the demos expire?

Demos are for evaluation. Production use requires a license; specific limits are documented in the demo package.

Do you provide source code or customization?

Depends on the engagement model. Custom development and technical support are available — contact us to discuss.
